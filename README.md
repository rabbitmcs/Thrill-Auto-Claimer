## What it does

Thrill posts cash drop codes that expire fast and get claimed within seconds. This extension watches for new codes and redeems them for you instantly — no copying, no pasting, no racing the clock.

- Claims every Thrill drop automatically
- Desktop notification when a code is claimed
- Pick the currency your bonus is credited in
- Live connection status and a log of recent claims

## Install

1. Download or clone this repo.
2. Open `chrome://extensions` in Chrome.
3. Turn on **Developer mode** (top right).
4. Click **Load unpacked** and select this folder.
5. Pin the extension and sign in to Thrill in the same browser.

## Usage

Click the extension icon to open the popup, turn on **Auto-claim**, and choose your currency. Leave it running — new codes are claimed in the background as they drop.

## Requirements

- Chrome 116 or newer
- A Thrill.com account, signed in
